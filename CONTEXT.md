# egouda.xyz

Personal website context for Essam Gouda's public portfolio, blog, and professional services.

## Language

**AI Workflow Consultant**:
A professional who builds focused AI-assisted workflows around a client's existing work, tools, and data.
_Avoid_: Chatbot builder, generic AI consultant

**AI Workflow**:
A specific, repeatable flow where software and AI use approved tools and data to complete useful work with clear human control.
_Avoid_: Generic chatbot, vague automation

**One-week AI Workflow Sprint**:
A fixed-price engagement for one agreed workflow: Sunday requirements, Monday-Saturday build, and a two-hour setup and review call the following Sunday.
_Avoid_: Subscription, unlimited development, free POC

**Paid Booking**:
A Sunday requirements slot confirmed by a Cal.com event only after its Stripe payment succeeds.
_Avoid_: Unpaid discovery call, shareable post-payment calendar link

**Mock Workflow Demo**:
A public, interactive example rebuilt from scratch with fictional names, values, files, and events. It may demonstrate an abstract interaction pattern but never contains private workspace or client data.
_Avoid_: Redacted production screenshot, copied fixture, anonymized personal export

**Services Question**:
One short pre-sale question answered from the fixed offer facts or handed off to egouda@bokralabs.com.
_Avoid_: Intake interview, generated project brief, persisted chat transcript

## Relationships

- An **AI Workflow Consultant** delivers one **AI Workflow** through a **One-week AI Workflow Sprint**.
- A **Paid Booking** reserves the first Sunday call for that sprint.
- **Mock Workflow Demos** show the shape of possible work without exposing private data.
- A **Services Question** clarifies the offer before a visitor pays and books.

## Example dialogue

> **Dev:** "Should the services page promise a chatbot?"
> **Domain expert:** "No. Show small working examples, state the fixed sprint, and send qualified buyers to paid Sunday booking."
